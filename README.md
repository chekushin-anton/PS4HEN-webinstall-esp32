# PS4HEN Web Installer (ESP32-S3)

Веб-установщик и офлайн-хост для PS4 на базе **ESP32-S3** (16 MB flash).
Пользователь открывает сайт в браузере Chrome/Edge, подключает плату по USB
и прошивает её одной кнопкой — включая веб-файлы в SPIFFS.
После прошивки ESP32 поднимает точку доступа и раздаёт локальный сайт.

## Возможности

- Прошивка ESP32-S3 прямо из браузера через Web Serial API (без Arduino IDE).
- Одна кнопка Install — записываются загрузчик, таблица разделов, прошивка и SPIFFS-образ.
- Автоматическая сборка при пуше в `main` через GitHub Actions.
- Публикация на GitHub Pages из папки `docs/` той же ветки `main`.
- Локальный веб-хост на ESP32: файлы из `data/` раздаются на `http://192.168.4.1`.

## Требования

- **Плата:** ESP32-S3 с flash **16 MB**.
- **Браузер:** Chrome, Edge или Opera (Web Serial API не поддерживается в Firefox/Safari).
- **Кабель:** USB с передачей данных (не «только зарядка»).
- **Для локальной сборки:** Arduino CLI с ядром ESP32, Python 3 (опционально).
