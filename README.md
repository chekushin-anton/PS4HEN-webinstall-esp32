# PS4HEN Web Installer — ESP32-S3

Веб-установщик и офлайн-хост для PS4 на базе **ESP32-S3 (16 MB flash)**.

Пользователь открывает сайт в браузере Chrome/Edge, подключает плату по USB
и прошивает её **одной кнопкой** — включая веб-файлы в SPIFFS. После прошивки
ESP32 поднимает точку доступа и раздаёт локальный сайт с эксплойтами для PS4.

---

## Возможности

- ✅ **Прошивка из браузера** — Web Serial API, без Arduino IDE и драйверов.
- ✅ **Одна кнопка Install** — загрузчик, таблица разделов, скетч и SPIFFS-образ.
- ✅ **Автосборка** — GitHub Actions пересобирает всё при каждом пуше в `main`.
- ✅ **GitHub Pages** — сайт-прошивальщик публикуется из папки `docs/` той же ветки.
- ✅ **Локальный веб-сервер на ESP32** — файлы из `data/` раздаются на `http://192.168.4.1`.
- ✅ **Универсальный FS** — скетч монтирует и LittleFS, и SPIFFS.

---

## Требования

| Компонент | Значение |
|---|---|
| **Плата** | ESP32-S3 с flash **16 MB** |
| **Браузер** | Chrome, Edge или Opera (Web Serial API) |
| **Кабель** | USB с передачей данных (не «только зарядка») |
| **Для локальной сборки** | Arduino CLI + ядро ESP32, Python 3 (опционально) |

> ⚠️ Firefox и Safari **не поддерживают** Web Serial — установщик в них не заработает.
