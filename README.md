# PS4HEN Web Installer

Веб-установщик и офлайн-хост для PS4. Перед прошивкой выберите модель платы и установленную версию PS4. Для C3, S2 и ESP8266 собирается образ только с подходящим набором эксплойтов. Для ESP32-S3 с flash 16 MB сохранён полный образ со всеми наборами.

## Поддерживаемые платы

- ESP32-C3 SuperMini и ESP32-C3 Zero с flash 4 MB
- ESP32-S2 Mini с flash 4 MB
- ESP8266 с flash 4 MB
- ESP32-S3 DevKit с flash 16 MB — полный образ

Платы C3 используют одну прошивку. Убедитесь, что у конкретной платы и её клона действительно 4 MB flash. Для ESP8266 используется разметка 4M3M: до 1 MB под приложение и 3 MB под LittleFS. Если у платы нет встроенного USB-UART, понадобится внешний адаптер.

## Варианты прошивки PS4

Наборы соответствуют имеющимся в `ESP32-S3-LittleFS-WebServer/data/ran` файлам эксплойтов:

- 5.05 и 5.07 — G2AllPro
- 6.70–9.60 — PSFree/Lapse, включая точку входа для 6.72
- 10.00–13.00 — G2AllPro
- 13.02–13.52 — набор эксплойта 13.5x

Список в установщике содержит версии, для которых в проекте есть соответствующий маршрут. Диапазон 6.00–6.69 и версии без подходящего эксплойта не предлагаются.

## Сборка и публикация

После отправки изменений в `main` или ручного запуска workflow **Build and publish PS4HEN web installer** он собирает прошивки плат, образы наборов PS4, создаёт манифесты веб-установщика и публикует содержимое `flasher/` в ветку `gh-pages`.

Для локальной сборки нужны Arduino CLI с установленными ядрами ESP32 и ESP8266, Python 3 и утилиты `mklittlefs` из этих ядер. Запустите `python tools/build_firmware.py` в корне репозитория или используйте `build_littlefs.bat`. Сгенерированные образы и манифесты появятся в `flasher/`.

Веб-прошивальщику нужен браузер с Web Serial, например Chrome или Edge.

После прошивки подключитесь к Wi-Fi `ps4hen` с паролем `88880000` и откройте `http://192.168.4.1`.
