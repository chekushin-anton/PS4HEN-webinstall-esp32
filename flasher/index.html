PS4HEN Web Install

Выберите плату и установленную прошивку PS4. Для небольших плат установщик запишет только подходящий набор файлов эксплойта.

▣
Выберите плату
Установщик подберёт образ для выбранной платы и PS4
Chrome · Edge · Компьютер с USB
Проверьте объём flash перед прошивкой. Сборки C3, S2 и ESP8266 рассчитаны на платы с 4 MB flash. ESP8266 подключается к компьютеру через USB-UART адаптер, если он не встроен в плату.

Если плата не подключится к Wi-Fi автоматически, подключитесь к сети ps4hen с паролем 88880000 и откройте http://192.168.4.1.

Укажите точную модель платы и прошивку PS4.
02
Подключите и прошейте
Нажмите кнопку и выберите последовательный порт платы.
03
Откройте хост
Подключитесь к Wi-Fi PS4HEN и откройте адрес ESP в браузере консоли.
